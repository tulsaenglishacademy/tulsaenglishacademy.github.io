# Tulsa English Academy Landing Page

Static landing page prepared for GitHub Pages.

## Publish
1. Upload `index.html` and `.nojekyll` to the repository root.
2. GitHub repository: `tonDG/tulsa-english-academy`
3. In Settings > Pages:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. Save.

Expected project-site URL:
https://tondg.github.io/tulsa-english-academy/
